# TVD2FiniteVolume

A reusable one-dimensional conservative finite-volume kernel using MUSCL
reconstruction, a selectable slope limiter, and SSP Runge-Kutta time marching.
The API uses only numeric arrays, structs, and function handles.

## Scope

The production interface solves

```text
dU/dt + divergence(F) = S(U,x,t)
```

from an initial condition. Spatial boundaries are explicit and may be
Dirichlet, linearly extrapolated outflow, zero-gradient, Neumann, or periodic.
Uniform and nonuniform cell faces are accepted. The bundled CFL controller is
based on the minimum geometric cell width.

If `CellMeasure` differs from geometric `CellWidth`, the library cannot infer
a stability limit from geometry alone; provide `options.TimeStep` explicitly.
Named limiters are followed by a geometry-aware face clamp, so reconstructed
traces remain inside adjacent cell-average bounds on stretched meshes.
The returned traces are therefore bounded MUSCL traces; on a stretched mesh
the two traces of one cell need not be generated by one unchanged linear
polynomial. A Neumann boundary value means the global-coordinate derivative
`dU/dx`, not an outward-normal derivative.

The term "TVD" has a precise limitation here: minmod/MC/van-Leer provide
bounded MUSCL face reconstruction, while a full total-variation guarantee
requires a scalar homogeneous conservation law, a monotone numerical flux,
an SSP integrator, and a suitable CFL number. Arbitrary source terms or
component-wise reconstruction of coupled systems do not inherit that theorem.
For Euler-like systems, reconstruct characteristic variables and provide an
appropriate Riemann flux.

Automatic stepping checks wave speeds at every SSP stage and retries a step
if a later stage increases the required CFL restriction. A custom
`NumericalFlux` must return a conservative monotone flux for a TVD claim.

## Minimal use

```matlab
root = fileparts(mfilename("fullpath"));
addpath(fullfile(root,"Solver"))

mesh = tvd2.makeMesh(linspace(0,1,101));
U0 = zeros(1,mesh.CellCount);

problem.Flux = @(U,x,t) U;                    % speed a = 1
problem.MaxWaveSpeed = @(UL,UR,x,t) ones(1,size(UL,2));
problem.Boundary.Left = tvd2.boundary("dirichlet",1);
problem.Boundary.Right = tvd2.boundary("outflow");

options = struct("Limiter","minmod","Integrator","ssp-rk2", ...
    "CFL",0.45);
result = tvd2.solve(problem,mesh,U0,linspace(0,0.5,6),options);
```

`problem.NumericalFlux(UL,UR,xFace,t)` may replace the default Rusanov flux.
If it is supplied, `problem.MaxWaveSpeed` is still required for automatic CFL
selection unless `options.TimeStep` is fixed.

## Important interfaces

- `tvd2.makeMesh`: validates faces and stores cell geometry.
- `tvd2.reconstruct`: returns left/right traces at every physical face.
- `tvd2.netFlux`: conservative integral net influx without assuming a cell
  capacity.
- `tvd2.divergence`: divides the outward flux difference by a caller-supplied
  cell measure.
- `tvd2.spatialOperator`: combines reconstruction, numerical flux, and source.
- `tvd2.solve`: SSP-RK2 or SSP-RK3 non-periodic time integration.

## Tests

```matlab
runTVD2Tests
```

Tests cover limiter behavior, nonuniform-grid linear reconstruction,
conservation, stretched-grid TVD behavior, flux broadcasting, bounded
non-periodic advection, and smooth-grid convergence.

## Optional validation layer

Only `Solver` belongs on the normal MATLAB path. For model integration work,
temporarily add `Tools` and run:

```matlab
addpath(fullfile(root,"Tools"))
report = tvd2tools.validateProblem(problem,mesh,U0,0,options);
diagnostics = tvd2tools.debug(problem,mesh,U0,0,options);
```

These functions deliberately repeat callbacks and calculate closure/limiter
diagnostics, so they are not invoked by `tvd2.solve`.
The normal solver defaults to `RuntimeChecks=false`; set it true only when
per-stage finite-value checks are useful during integration.
