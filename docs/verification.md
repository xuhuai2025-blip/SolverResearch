# 验证记录

日期：2026-10-23。环境：Windows x64、Python 3.13.15、NumPy 2.2.6、SciPy 1.15.3、scipy-dae 0.1.1。

## 独立安装

普通平台 wheel 安装到专用虚拟环境，不使用可编辑安装。从源码目录以外，以 `python -I` 运行测试和三个示例，导入路径位于安装环境的 site-packages。`pip check` 无依赖冲突。

安装包为 `py3-none-win_amd64`，包含 ctypes/C ABI 原生库，未将它标为任意平台可用的纯 Python wheel。瞬态包依赖固定版本的第三方 BDF/DAE 后端。

## 非线性核心

- 17 个 Python 模块去除说明文字后的运算结构、控制流和数值常量一致。
- ABI 2 原生调度库按字节相同。
- 3 组独立代数方程的状态、残差、迭代轨迹和计数与复制前一致。
- 已知根、边界与尺度、独立运行时、错误传播、取消、依赖失效和事务回退均通过专项测试。

普通耦合方程示例的两个分量均为 `1.3027756377319946`，完整残差无穷范数为 0。

## 瞬态积分

23 项专项检查的当前版本均通过，包括 5 项非线性检查和 18 项瞬态检查。首轮失败的两项事件检查在修正单状态插值形状后单独复查；新增检查单独执行，其余通过项未重复运行。

## 边界

本次没有重跑 MATLAB，也没有声称两个后端的步长、阶数或数值轨迹相同。上表是 Python 版对解析解的验证。

本次没有运行领域整机、GUI 或其他无关测试，没有修改调用方的物理方程或原工程。非线性核心原生加载器现有支持 Windows x64/macOS arm64，本次仅在 Windows 验收；不声称已经完成 Linux 或 macOS 实机验证。

稀疏初始化可接收稀疏解析雅可比，但一致初值阶段使用稠密 QR，超大规模初值校正需评估内存。后端使用部分 SciPy 私有接口，升级 SciPy/scipy-dae 版本前应重新执行本仓库的专项检查。
